Cutline's browser pin is explicit and does not follow Remotion's default browser download. Review Remotion dependency pins, the browser version and launch mode, the manifest and these notices together. Manifest changes must come from a newly verified trusted upstream archive, not the existing `vendor/` cache. The source release includes the manifest, not the browser application.
