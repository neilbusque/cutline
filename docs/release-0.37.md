# Cutline 0.37

Cutline can now review the full soundtrack automatically before finishing an export, from the app or an assistant.

- Optional hosted Qwen audio review checks voice, music and sound effects alongside local peak, loudness and caption-alignment evidence.
- Explicit audio roles provide isolated native mixes for supported corrections.
- Supported fixes receive a new export and a complete second review before becoming one undoable timeline change.
- Failed reviews, uncertain findings, stale revisions and possible regressions preserve the original export and report what remains.
- Shared settings, cancellation, progress and per-export review reports keep the workflow visible.

See [Listening review](listening-review.md) for setup, data sharing, supported fixes and limitations. Earlier: [0.36](release-0.36.md).
