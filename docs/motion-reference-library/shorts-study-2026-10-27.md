# Cutline short-form motion research

Research refreshed 27 October 2026. Primary public metadata was retrieved directly with yt-dlp. View/like counts below are snapshots, not claims that effects caused performance. Web fetches of the platform pages were throttled; direct public media/metadata access succeeded. No login, paid generation, personal-data upload, or browser session was used.

## What the evidence supports

Recent creator references repeatedly combine a speaking subject or a persistent explanatory object with changing diagrams, screens, and purposeful changes in scale. A successful visual explains a transformation: a packet travels, a chart develops, a screen becomes the main subject, or an object arrives in its final state. This is a more useful product target than adding many interchangeable entrances.

These are **recent and popular references**, not a verified platform-wide October trend ranking. YouTube's September 2025 [creative maximalism report](https://blog.youtube/culture-and-trends/next-gen-creativity/) identified dense visual/audio information and faster editing as part of a broad creative pattern. Its September 2026 [mainstream-culture report](https://blog.youtube/culture-and-trends/youtube-culture-trends-modern-mainstream-research/) emphasizes niche communities and participation. Neither proves that a particular transition increases retention, or that every explainer should have maximal density.

## Ranked capability matrix

The Cutline 0.37 source audit confirmed cubic easing, stroke trim, masked per-line type, 2.5D plane rotation, editable layers, and scene templates. Version 0.38 adds the three native primitives below.

| Priority | Mechanism | Why it matters / evidence | Native upgrade and acceptance |
|---|---|---|---|
| 1 | Object follows a curved route with optional orientation | Rick's data journey and map, Jack's causal node/output chain, Aasil's traced route | Reusable authored path plus animatable progress. Auto-orientation uses the tangent. Combine with independently trimmed route stroke. Check start/end poses, corners, reverse travel, frame seeking and portrait/landscape output. Source geometry and route stay editable. |
| 2 | Animated per-layer wipe and iris reveal | Reference proof changes and transitions rely on useful occlusion; existing line masks do not cover all graphic layers | Explicit reveal progress, direction and iris behavior with clean settled state. Check 0%, midpoint and 100% plus rotation/scale combinations. Call these masks/reveals. They are not arbitrary alpha track mattes, rotoscoping, or subject separation. |
| 3 | Deterministic numbers and data development | Aasil's bar charts and count scenes; Rick's staged quantity/packet explanation | Keyframed value, decimals/prefix/suffix, exact final value and seek-stable formatting. Couple a bar/arc/path reveal to the same authored progress when the quantity is meant to be proportional. Use illustrative labels where numbers are examples, not business proof. |
| Supporting | A small set of authored explainer scenes | Three sources visibly vary explanation mechanisms while preserving a coherent world | Distinct route/process, data/stat, comparison, depth and focal-reveal scenes. Adapt composition for portrait and landscape instead of scaling a landscape layout down. Each must show a state change and a readable outcome. Avoid standard title-plus-card layouts in all five. |
| Later | Shared group/null transforms and nested composition | Aasil's plane and label move as a single object | True parent transforms preserve relative positions; synchronized independent keys are a workaround. Do not advertise grouping until it exists. |
| Later | True motion blur and alpha/luma mattes | Core AE compositing primitives, not established source settings | Velocity/temporal blur should remain distinct from a static blur filter. Alpha/luma sources, subject cutout and 3D cameras are separate capabilities requiring their own implementation. |

## Adobe primary technical references

- [Animate along a path](https://helpx.adobe.com/lv/after-effects/how-to/animate-along-path.html) and [layer auto-orientation](https://helpx.adobe.com/after-effects/desktop/work-with-layers/select-and-arrange-layers/selecting-arranging-layers.html): path motion and tangent-facing orientation are separate controls. Cutline can implement an original, deterministic native equivalent without importing an AE project.
- [Shape attributes and Trim Paths](https://helpx.adobe.com/after-effects/desktop/drawing-painting-and-paths/shapes-and-shape-attributes/shape-attributes-paint-operations-path.html): animating a stroke's start/end/offset reveals a path. A route stroke drawing and an object following it should remain independently editable.
- [Text animators and selectors](https://helpx.adobe.com/after-effects/desktop/animating-text/text-animation/animating-text.html), updated 30 Apr 2026: ranges may target characters, words or lines and affect properties. Cutline's existing masked line reveal is a useful subset, not full text-animator parity.
- [Track mattes](https://helpx.adobe.com/after-effects/using/track-mattes-and-traveling-mattes.html): a separate layer can determine another layer's visibility. An iris/wipe is a narrower feature; do not call it full track-matte support.
- [Assorted animation tools / motion blur](https://helpx.adobe.com/after-effects/desktop/animate-in-after-effects/assorted-animation-tools/assorted-animation-tools.html): motion blur addresses frame-to-frame movement. A keyframed blur amount is not automatically equivalent.
- [Animated infographic](https://helpx.adobe.com/ph_fil/after-effects/how-to/animated-infographic.html): a small set of editable shape strokes can produce a developing data graphic. Supports the choice of reusable primitives over rasterized visual demos.
