1. Identify the film's real subject and ending payoff. Choose a format supported by the available footage.
2. Inspect the few reference passages that answer the actual creative question. Record what was observed and what is inferred.
3. Fill the brief and beat sheet. Select one visual mechanism for each idea, then timing, transition, sound and grade.
4. Build a representative moving passage. Review subject scale, action, reading holds, continuity, captions and sound.
