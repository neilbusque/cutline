# Cutline 0.38

Native motion paths, reveal masks and number counters make informational Shorts easier to author and refine.

- Four-point curved paths with distance-based progress and optional tangent rotation
- Animated directional wipes and center iris masks for native layers
- Deterministic number counters with editable values, timing, decimals, prefixes and suffixes
- Five explainer scenes with distinct visual mechanisms and portrait/landscape layouts
- Inspector controls, assistant schema, keyframe curves, canvas resizing and timing support

Everything remains editable and uses the same renderer for preview and export. No paid generation is required. Existing projects keep their previous appearance when the optional new fields are absent.

See [Explainer motion](premium-motion.md) for controls and boundaries. Earlier: [0.37](release-0.37.md).
